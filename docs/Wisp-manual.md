# Wisp 앱 매뉴얼

> 앱 버전 1.0 기준. 앱 소스(도움말 목록, 문자열 리소스, 빌드 설정)를 바탕으로 작성했어요.

---

## 1. 앱 개요

Wisp은 안드로이드 기기에서 메신저 알림을 받아 자동으로 답장하는 봇 앱이에요. 스크립트(JavaScript)를 써서 명령어 응답, 공지 전달, 시간 재기 같은 동작을 만들 수 있어요.

| 항목 | 내용 |
| --- | --- |
| 앱 이름 | Wisp (위스프) |
| 패키지 | io.github.highkrs.wisp |
| 스크립트 엔진 | Mozilla Rhino 1.9.1 (인터프리터 모드) |
| 스크립트 언어 | JavaScript (ES5 레거시 API, ES6 API2) |
| 저장 위치 | /sdcard/Wisp |

**이런 분께 맞아요**
- 메신저 자동 응답이나 알림 기반 작업을 직접 만들어 보려는 분
- JavaScript를 조금 다룰 수 있는 분

## 2. 설치 및 처음 실행

### 2-1. 준비 사항

앱은 안드로이드 12L(API 32) 이상 기기에서 쓸 수 있어요.

| 항목 | 조건 |
| --- | --- |
| 빌드 환경 | Android Studio, JDK 11 이상 |
| compileSdk | 36 |
| targetSdk | 35 |
| minSdk | 32 |

### 2-2. 필요한 권한

설치한 뒤 아래 3가지 권한을 허용해 주세요.

| 권한 | 어디서 허용 | 없으면 |
| --- | --- | --- |
| 알림 접근 | 설정 > 권한과 안정성 > 알림 접근 | 메신저 메시지를 받지 못해요 |
| 모든 파일 접근 | 설정 > 권한과 안정성 > 모든 파일 접근 | /sdcard/Wisp 폴더를 쓸 수 없어요 |
| 배터리 최적화 제외 | 설정 > 권한과 안정성 > 배터리 최적화 제외 | 절전 때문에 봇이 멈출 수 있어요 |

### 2-3. 처음 실행 순서

1. 앱을 열고 **+ 버튼**으로 새 프로젝트를 만들어요. 이름과 사용할 API를 고르세요. **API2(권장)**를 고르는 것을 추천해요. 프로젝트를 만든 뒤에는 API를 바꿀 수 없어요.
2. 프로젝트를 누르고 **+ 스크립트**로 새 스크립트를 만들어요.
3. 스크립트를 열어 코드를 적고 저장해요.
4. **컴파일**을 눌러요. 오류가 있으면 해당 줄로 이동해요.
5. 스크립트와 프로젝트를 켜고, 메신저에서 메시지를 보내 확인해요.

> 실제 메신저를 쓰기 전에 **테스트룸**에서 먼저 시험해 보세요. 테스트룸에서 보낸 메시지는 스크립트에만 전달돼요.

## 3. 주요 기능

### 3-1. 프로젝트 목록 (메인 화면)

| 기능 | 설명 |
| --- | --- |
| 프로젝트 만들기 | + 버튼으로 새 프로젝트를 만들고 사용할 API를 골라요 |
| 검색 | 프로젝트와 스크립트 이름으로 찾아요 |
| 정렬 | 이름순, 최근 수정순, 최근 컴파일순, 켜진 것 먼저, API별, 상태별(오류 먼저) |
| 보기 방식 | 목록, 바둑판, 간단히 보기 중에 골라요 |
| 즐겨찾기 | ★ 표시로 자주 쓰는 프로젝트를 목록 맨 위에 모아요 |
| 순서 바꾸기 | 카드를 길게 누른 채 끌면 순서가 바뀌어요 |
| 내보내기 · 가져오기 | 프로젝트 하나를 파일로 내보내고, 다른 기기에서 가져와요 |

### 3-2. 프로젝트 화면

| 기능 | 설명 |
| --- | --- |
| 스크립트 만들기 | + 버튼으로 새 스크립트를 만들어요 |
| 프로젝트 켜기 | 프로젝트 전체를 켜거나 꺼요. 꺼진 프로젝트는 스크립트도 멈춰요 |
| 전체 컴파일 | 프로젝트의 모든 스크립트를 다시 컴파일해요 |
| 시작 순서 | 앱을 켤 때 컴파일할 순서를 정해요 (아래 3-4 참고) |
| 이름 변경 · 삭제 | 프로젝트 이름을 바꾸거나 지워요. 삭제는 되돌릴 수 없어요 |

### 3-3. 스크립트 편집 화면

| 기능 | 설명 |
| --- | --- |
| 코드 편집 | JavaScript를 쓰고, 자동 들여쓰기와 괄호 닫기를 쓸 수 있어요 (편집기 설정에서 끌 수 있어요) |
| 찾기 · 바꾸기 | 위치를 정해 여러 곳을 한 번에 바꿔요. 대소문자 구분 옵션도 있어요 |
| 실행 취소 · 다시 실행 | 편집 내용을 되돌리거나 다시 적용해요 |
| 파일에서 다시 읽기 | 저장된 파일 내용으로 편집 화면을 다시 채워요. 저장하지 않은 변경은 사라져요 |
| 컴파일 | 스크립트를 실행 가능한 상태로 만들어요. 오류는 줄 번호와 함께 보여요 |
| 화면 열기 | onCreate가 있는 스크립트라면 만든 화면을 바로 볼 수 있어요 |
| 변수 보기 | 스크립트가 만든 전역 변수를 볼 수 있어요. 실행 중일 때만 나와요 |
| 테스트룸 | 보낸 것처럼 메시지를 입력해 스크립트 동작을 시험해요 |

### 3-4. 시작 순서

앱을 켤 때 스크립트를 위에서부터 차례로 컴파일해요. 앞 스크립트가 전역 값을 만들면 뒤 스크립트가 그 값을 쓸 수 있어요.

- 끌어서 순서를 바꿀 수 있어요.
- **위로 / 아래로** 버튼으로도 옮길 수 있어요.
- **의존 순서로 자동 정렬**: 파일끼리 부르는 순서에 맞춰 정렬해요.
- **기본 순서로**: 직접 정한 순서를 지우고 처음 상태로 되돌려요.

### 3-5. 설정에서 바꾸는 항목

- **응답할 메신저**: 봇이 답장할 메신저 패키지를 고르거나, 패키지명을 직접 추가해요 (예: com.example.messenger).
- **수신 메시지 기록**: 디버깅용으로 받은 메시지를 실행 로그에 남겨요.
- **시작할 때 미리 컴파일**: 켜진 스크립트를 앱 시작 때 컴파일해 둬요.
- **꺼진 스크립트도 미리 컴파일**: 켜기 전에 컴파일만 해 둬요. 실행은 하지 않아요.
- **기본 글로벌 모듈 다시 만들기**: 지워진 기본 모듈만 다시 넣어요. 고친 파일은 그대로 둬요.
- **무한루프 방지**: CPU 시간으로 10초 넘게 계속 돌면 스크립트를 멈춰요. 끄면 무한루프 스크립트가 봇 전체를 멈출 수 있어요.
- **테마**: 밤하늘, 새벽, 저녁 노을, 숲, 바다 중에서 고를 수 있어요.
- **시작 연출 건너뛰기 · 배경 애니메이션**: 시작 화면 연출과 별 애니메이션을 끌 수 있어요. 애니메이션을 끄면 배터리를 아껴요.

### 3-6. 테스트룸 · 메시지 콘솔 · 실행 로그

- **테스트룸**: 메시지를 입력해 스크립트에 보내요. 실제 메신저로는 나가지 않아요.
- **메시지 콘솔**: 받은 메시지(받음)와 보낸 메시지(보냄)를 기록해요. 보내지 못한 메시지는 "보내지 못함"으로 표시돼요.
- **실행 로그**: 정보, 경고, 오류, 수신 필터로 골라 봐요. 검색하고, 모두 복사하거나 지울 수 있어요. 프로젝트나 스크립트별로도 거를 수 있어요.

### 3-7. 홈 화면 위젯

홈 화면에 Wisp 컨트롤 패널을 올릴 수 있어요.

- **전체 컴파일**: 모든 프로젝트를 컴파일해요.
- **전체 끄기 · 전체 켜기**: 모든 프로젝트를 한 번에 꺼거나 켜요.
- **최근 메시지**: 최근에 받은 메시지를 보여줘요.
- **앱 열기**: 앱을 바로 열어요.

### 3-8. 도움말

앱 안의 도움말에서 API 예제를 볼 수 있어요. **예제 복사**로 클립보드에 옮기거나, **새 스크립트로 만들기**로 바로 스크립트를 만들 수 있어요.

## 4. 스크립트 예제 (API2)

```javascript
const bot = BotManager.getCurrentBot();

bot.addListener("command", (msg) => {
    if (msg.command === "더하기") {
        const sum = msg.args.map(Number).reduce((a, b) => a + b, 0);
        msg.reply("합계는 " + sum + " 이에요");
    }
});
```

위 코드를 스크립트에 적고 컴파일한 뒤, 테스트룸에서 `더하기 2 3`을 보내면 `합계는 5 이에요`로 답해요.

**주요 API2 함수**

| 함수 | 설명 |
| --- | --- |
| `BotManager.getCurrentBot()` | 이 스크립트의 Bot 객체를 얻어요 |
| `bot.addListener(event, fn)` | 이벤트가 올 때 fn을 호출해요 |
| `"message"` 이벤트 | 메시지가 올 때마다 호출돼요 |
| `"command"` 이벤트 | 접두어가 붙은 명령어가 올 때 호출돼요. `msg.command`, `msg.args`를 써요 |
| `msg.reply(text)` | 메시지가 온 방에 답장해요 |
| `bot.send(room, msg)` | 지정한 방에 메시지를 보내요 |
| `bot.canReply(room)` | 그 방에 답장할 수 있는지 확인해요 |
| `setTimeout` · `setInterval` | 지정한 시간 뒤 또는 간격마다 실행해요 |
| `Database.readString` · `writeString` | 스크립트 전용 파일에 값을 저장해요 |
| `console.log` · `info` · `warn` · `error` | 실행 로그에 남겨요 |

## 5. 문제 해결

### 5-1. 증상별 확인 방법

| 증상 | 확인할 것 |
| --- | --- |
| 메시지를 못 받아요 | 메인 화면의 알림 접근 배너가 없는지, 알림 접근이 허용돼 있는지 확인하세요. 프로젝트와 스크립트가 켜져 있는지도 보세요 |
| 백그라운드에서 봇이 멈춰요 | 배터리 최적화 제외를 허용하세요 |
| 답장이 안 나가요 | 실행 로그에서 오류를 확인하세요. 방이 닫혀 있으면 전송에 실패해요 (메시지 콘솔에 "보내지 못함"으로 보여요) |
| 스크립트를 고쳤는데 반영이 안 돼요 | 저장만으로는 반영되지 않아요. 컴파일을 눌러 새로 시작하세요 |
| 스크립트가 멈춰요 | 설정의 무한루프 방지가 켜져 있는지 확인하세요. 꺼져 있으면 무한루프 스크립트가 봇 전체를 멈출 수 있어요 |
| 저장 경로를 찾을 수 없다고 해요 | 모든 파일 접근을 허용해야 /sdcard/Wisp 폴더를 쓸 수 있어요 |
| 컴파일 오류가 나요 | 오류 메시지를 누르면 해당 줄로 이동해요 |
| 시작할 때 스크립트끼리 값이 안 맞아요 | 시작 순서 화면에서 값을 만드는 스크립트를 위로 올리거나, 의존 순서로 자동 정렬하세요 |
| 기본 글로벌 모듈이 사라졌어요 | 설정에서 기본 글로벌 모듈 다시 만들기를 누르세요. 고친 파일은 그대로 남아요 |

### 5-2. 자주 묻는 질문

- **API를 나중에 바꿀 수 있나요?** 아니요. 프로젝트를 만든 뒤에는 API를 바꿀 수 없어요. 다른 API로 쓰려면 새 프로젝트를 만드세요.
- **삭제한 프로젝트를 되돌릴 수 있나요?** 아니요. 프로젝트 안의 스크립트까지 모두 지워지고 되돌릴 수 없어요. 삭제 전에 내보내기를 해 두세요.
- **데이터는 어디에 저장되나요?** /sdcard/Wisp 폴더에 저장돼요.
- **테스트룸 메시지가 실제 메신저로 나가나요?** 아니요. 테스트룸 메시지는 스크립트에만 전달돼요.
